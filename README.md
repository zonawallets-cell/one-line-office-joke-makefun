Entry for the make.fun bounty
[One-Line Office Joke: 24-Hour Sprint](https://make.fun/competitions/u-pucuys-one-line-office-joke-24-hour-sprint-aaf86162).

`main.py` writes a single original one-line joke about office life
(at most 200 characters) to `/output/entry.txt`. Pure Python standard
library, deterministic — the same line on every run.

## The line

> We passed Dave's birthday card around the office for so long that by the time it reached his desk, it was his next birthday.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
